# Bill Splitter

A Python-based bill splitter utility that calculates how much each person should pay when splitting a bill fairly. This project was created as a learning exercise through FreeCodeCamp to practice Python fundamentals including input handling, arithmetic operations, and user-friendly output.

## 🎯 Project Overview

This tool helps you:
- Input the total bill amount
- Specify the number of people splitting the bill
- Calculate the exact amount each person owes
- Display results in a clear, easy-to-read format

## 📁 Project Structure

This repository contains the Bill Splitter implementation with Python best practices for beginner-level development.
